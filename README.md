# Скан в Таблицу

Бесплатная замена приложению Scan-IT to Office: телефон сканирует штрих-коды камерой и отправляет их в Google Таблицу.
Без демо-режима, без ограничений и без потери данных.

## Почему данные больше не теряются

| Проблема в Scan-IT to Office | Как решено здесь |
|---|---|
| Скан пропадает при ошибке сети | Каждый скан **сначала сохраняется в памяти телефона**, потом отправляется. Помечается ✅ только когда таблица подтвердила запись |
| Ошибки при отправке | Автоматические повторы: сразу, при появлении сети, при открытии приложения и раз в минуту |
| Дубли при повторной отправке | У каждого скана свой ID. Скрипт таблицы не записывает один ID дважды |
| Несколько телефонов пишут одновременно | Скрипт пишет в таблицу строго по очереди (блокировка) |
| Длинные коды превращаются в `4,6E+12`, пропадают ведущие нули | Колонка со штрих-кодом записывается как текст |
| Демо-версия и лимиты | Своё приложение, никаких лимитов |

На экране всегда видно: **⏳ N** — сколько сканов ещё ждёт отправки, **✔ N** — сколько уже в таблице.
Во вкладке «История» можно отправить вручную или выгрузить всё в CSV (резервная копия).

## Настройка (один раз, ~10 минут)

### Шаг 1. Подключите Google Таблицу

1. Откройте (или создайте) Google Таблицу, куда должны попадать сканы.
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое файла [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
4. Нажмите 💾 «Сохранить».
5. Справа вверху **Развернуть → Новое развертывание**. Нажмите ⚙️ рядом с «Выберите тип» → **Веб-приложение**:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
6. **Развернуть** → разрешите доступ своему аккаунту Google (если Google предупредит «Приложение не проверено» — «Дополнительно» → «Перейти к проекту»).
7. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

> Необязательно: чтобы посторонние не могли писать в таблицу, впишите в `Code.gs` строку `var SECRET = 'любой-пароль';`
> и тот же пароль укажите в приложении в поле «Секретный ключ». После изменения кода: **Развернуть → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть** (URL не меняется).

### Шаг 2. Опубликуйте приложение (GitHub Pages)

Приложение — это сайт, камера работает только по `https`, поэтому его нужно опубликовать:

1. В репозитории на GitHub: **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты приложение будет доступно по адресу вида
   `https://yulek6644-prog.github.io/-/`

(На бесплатном тарифе GitHub Pages работает для публичных репозиториев. Код не содержит ничего секретного — адрес таблицы хранится только в телефонах.)

### Шаг 3. Установите на свой телефон

1. Откройте адрес приложения:
   - **Android** — в Chrome. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
   - **iPhone** — в Safari. Кнопка «Поделиться» → **На экран «Домой»**.
2. Откройте приложение с иконки → **Настройки**:
   - вставьте URL из шага 1;
   - «Лист в таблице» — имя листа (создастся сам, по умолчанию «Данные»);
   - «Имя устройства / сотрудника» — чтобы в таблице было видно, кто сканировал.
3. **Сохранить** → **Проверить связь** — должно появиться «Связь есть ✔».
4. Вкладка «Сканер» → **Старт** → разрешите доступ к камере.

### Шаг 4. Установите другим

В **Настройках** нажмите **«Поделиться ссылкой»** и отправьте её в WhatsApp/Telegram.
Человек открывает ссылку, соглашается применить настройки, вводит своё имя — и устанавливает приложение как в шаге 3.

## Что попадает в таблицу

Строки пишутся в том же формате, что и у Scan-IT to Office на листе «Данные» (новая строка — сразу после последней заполненной в колонке A):

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| Артикул | Дата | Наименование (формула ВПР по листу «номенклатура») | Количество (− расход, + приход) | Комментарий (П.907 и т.п.) | - | Устройство | - | Время скана | Время записи | ID скана |

Колонку K «ID скана» не удаляйте и не меняйте — по ней отсекаются дубли. Её можно скрыть.

В приложении над полем количества есть переключатель **«− Расход / + Приход»**: при «Расходе» количество записывается с минусом.

## Возможности

- Штрих-коды EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, Codabar, ITF, а также QR, DataMatrix, PDF417, Aztec.
- Работает на Android и iPhone; открывается и сканирует без интернета.
- Количество и комментарий к скану, ручной ввод кода, режим «спрашивать количество после каждого скана».
- Защита от случайного двойного скана того же кода (пауза настраивается).
- Звук, вибрация, фонарик (если телефон поддерживает), экран не гаснет во время сканирования.
- Каждый скан можно отправить на свой лист (поле «Лист в таблице»).

## Частые вопросы

**Горит «Ошибка отправки».** Данные в безопасности на телефоне. Проверьте интернет и нажмите «Проверить связь» в настройках.
Если ответ «не JSON» — в развертывании скрипта не выбран доступ «Все», либо скопирован URL не от веб-приложения.

**Можно ли удалить приложение/почистить браузер?** Пока на значке ⏳ не 0 — нет: неотправленные сканы хранятся в телефоне.
Если нужно, сначала выгрузите CSV во вкладке «История».

**Как обновить приложение?** Изменения в репозитории подхватываются автоматически при следующем открытии.
При выпуске новой версии увеличьте номер `CACHE` в `sw.js`.

## Файлы

- `index.html`, `style.css`, `app.js` — приложение.
- `sw.js`, `manifest.webmanifest`, `icons/` — установка на телефон и работа без интернета.
- `vendor/` — распознавание штрих-кодов ([barcode-detector](https://github.com/Sec-ant/barcode-detector) / ZXing, лицензия MIT), хранится локально, чтобы работало офлайн.
- `google-apps-script/Code.gs` — скрипт для Google Таблицы.
